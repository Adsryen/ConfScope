## 面板协作规矩（三个面板共享同一份工作区 `/home/ryen/Git/ConfScope`）

0. 测试只跑与自己改动相关的子集，全量串由 c 在每波合入前统一跑（三方并发会抢 CPU）。
   `.git/index.lock` 被占说明别人正在提交，等 3 秒重试，不删别人的 lock。

1. 只 `git add` 自己写范围内的路径，禁止 `git add -A` / `git add .`。
2. 禁止 `checkout` / `switch` / `stash` / `rebase` / `reset` / `clean`——会动到别人未提交的内容。
3. 提交遵守 `.trae/rules/git-commit-message.md`：Conventional Commits、中文、
   **标题 + 短 bullet 正文缺一不可**、不用 emoji、不写内部代号（轮N / 守卫 / 判据 / 兜底 / 收口）。
4. 不许为了让测试变绿放宽断言。
5. `CHANGELOG.md`、`docs/todo/**`、`README*`、`package.json`、`wails.json`、`.trellis/**` 归 c 独占。
6. 真机 retest（Playwright + 127.0.0.1:1420 的 vite dev）只由 c 跑，避免端口与数据目录打架。
7. 打 tag / 推 release 只走 c，且必须先拿到用户当轮原话（§0.3）。
8. `src/locales/zh-CN.json` 与 `src/locales/en-US.json` 是两个面板同时会写的共享文件：
   新文案 key 先落在自己任务目录的 `research/locales.md`，提交前最后一步才动 locale 文件，
   动之前重读当前内容只做定点插入，绝不整文件重写；看到不是自己写且未提交的内容先报 c。

## 已备好的实测素材（c 落盘，p2 直接取用，不要重复调研）

- **r105**：`.trellis/tasks/10-27-r105-securestore-cross-platform/research/linux-secret-service-env.md`
  容器 `confscope-r105-secret-service` 里真端点的往返读数 `store_rc=0`、`lookup_value=[hunter2]`、`clear_rc=0`、
  删除后再查 `rc=1`。要点三条：起服务要用 `gnome-keyring-daemon --unlock --components=secrets --replace`
  并从 stdin 喂口令（`--start` 在容器里拿不到 `login` 集合，store 直接失败）；`XDG_RUNTIME_DIR` 必须预建且 0700；
  接口名是 `org.freedesktop.Secret.Service`（大写 S），照规范字面量写成小写会报 `No such interface`。
  同目录两个脚本 `verify-secret-service.sh` / `probe-dbus-introspect.sh` 可直接 `docker cp` 进容器复跑。
- **r106**：`.trellis/tasks/10-27-r106-arm64-builds/research/runner-and-nsis-arm64.md`
  runner 标签 `ubuntu-24.04-arm`（2025-08-07 GA，公开仓库免费）与 `windows-11-arm`（2025-04-14 起 preview）；
  NSIS 上游只有 "Preliminary ARM64 support in makensis.nsi"，常用发行版明写不支持 arm64 ⇒ windows-arm64 第一版按
  「只出便携包」规划。`release.yml` 里 8 处 `amd64` / `x86_64` 硬编码逐条带行号，连同
  `internal/updatecheck/artifact.go:42-53` 的资产名表一起列在文件里。
